# 翻譯腔對照表

翻譯腔的成因是先有英文句子，再把每個詞換成中文。句子的骨架還是英文的，所以讀起來卡。修法是先弄懂這句話的意思，再用中文重新講一次，不要看著英文的語序寫。

## 目錄

1. 硬翻的慣用語
2. 翻譯腔名詞
3. 句法
4. 英文詞要不要翻
5. 人名、公司名、數字

---

## 1. 硬翻的慣用語

想不到對應的中文說法，就把意思講白。不要留一個中文讀者得先翻回英文才看得懂的比喻。

| 英文 | 硬翻 | 自然的說法 |
|---|---|---|
| eat their lunch | 把他們的午餐吃掉 | 搶他們的生意 |
| jaw-dropping | 讓人下巴掉下來 | 讓人看傻眼 |
| go down the rabbit hole | 掉進兔子洞 | 一頭栽進去／越挖越深 |
| everyone in the room | 房間裡的每個人 | 在場的人 |
| shiny objects | 閃亮的東西 | 看起來值得一試的新東西 |
| unfair advantage | 不公平的優勢 | 別人很難追上的優勢 |
| the upside is huge | 上檔很高 | 能得到的東西很多 |
| put your foot down | 把腳踩穩 | 把立場站穩 |
| at the end of the day | 在一天結束的時候 | 說到底 |
| low-hanging fruit | 低垂的果實 | 最容易做的那幾件 |
| move the needle | 移動指針 | 有明顯的效果 |
| on the same page | 在同一頁上 | 想法一致 |
| take it with a grain of salt | 帶著一粒鹽 | 聽聽就好 |
| the elephant in the room | 房間裡的大象 | 大家都知道卻沒人提的事 |
| boil the ocean | 把海水煮沸 | 可以保留原文再解釋：想一次做完所有事 |
| run through walls | 穿牆而過 | 硬著頭皮撞過去 |
| skin in the game | 皮膚在遊戲裡 | 自己也押了錢／自己也有風險 |
| double down | 加倍下注 | 加碼／更用力做 |
| a seat at the table | 桌邊的位子 | 說得上話 |
| on the other side of the table | 桌子的另一邊 | 這個中文也通，可以留 |

最後一列是提醒：有些比喻中文本來就通，不用硬改。判斷標準是沒看過英文的人讀不讀得懂。

## 2. 翻譯腔名詞

| 翻譯腔 | 改成 |
|---|---|
| 洞見、洞察 | 發現、看法、看懂的事 |
| 框架（指思考方式） | 觀念、想法、看事情的方法 |
| 學習迴圈 | learning loop，或「邊做邊學的速度」 |
| 痛點 | 困擾、麻煩、卡住的地方（商業文章裡「痛點」已經通用，偶爾用可以） |
| 賦能 | 讓…做得到 |
| 落地 | 做出來、實際用上 |
| 顆粒度 | 細到什麼程度 |
| 心智模型 | 想法、理解方式 |
| 敘事 | 說法、故事 |
| 願景 | 想做成的事（公司正式文件裡可以用） |
| 可擴展性 | 能不能放大 |
| 利益相關者 | 相關的人、要顧到的人 |

## 3. 句法

### 句句補主詞

英文每句都要主詞，中文不用。見 SKILL.md 第 1 條。

### 「作為」「身為」開頭

> ✗ 作為一個工程師，我習慣先想架構。
> ✓ 工程師出身，習慣先想架構。

### 「進行」「做出」「加以」加名詞

把動詞變成名詞，再配一個空的動詞。

> ✗ 對使用者進行訪談／做出決定／加以改善
> ✓ 訪談使用者／決定／改善

### 「被」字句

英文的被動多半可以改成主動，或用「讓」「給」「受到」，或乾脆省略施事者。

> ✗ 這家公司在 2019 年被 Philips 收購。
> ✓ 這家公司 2019 年賣給 Philips。（「被收購」本身很通用，也可以留。連著三句都是「被」才需要改。）

> ✗ 他被要求全職投入。
> ✓ 投資人要他全職。

### 「們」

中文的複數通常不用標。

> ✗ 創辦人們、使用者們、開發者們
> ✓ 創辦人、使用者、開發者

### 「一個」「一種」「一項」

> ✗ 他是一個醫生。這是一種新的方法。
> ✓ 他是醫生。這是新方法。

### 「的」連用和長定語

英文的關係子句直接搬過來，會變成一長串「的」。拆成兩句。

> ✗ 那個在 2015 年創辦了一家做東南亞支付的公司的創辦人說…
> ✓ 他 2015 年創辦了一家做東南亞支付的公司。他說…

### 「性」「化」「度」結尾的抽象名詞

> ✗ 有很高的可能性會失敗。提升了可讀性。
> ✓ 很可能失敗。比較好讀了。

### 「之一」

「最重要的事情之一」是 one of the most 的直譯。多數時候可以改成「很重要」，或直接講它。

> ✗ 這是我做過最好的決定之一。
> ✓ 這個決定做對了。

### 「當…的時候」「如果…的話，那麼…」

> ✗ 當他去美國的時候，他不會說英文。
> ✓ 剛去美國時不會講英文。

### 「這使得」「這意味著」「這讓」

用「這」指前面一整句，是英文 this/which 的搬法。改成「所以」「於是」，或把兩句併起來。

> ✗ 軟體一上線就能觸及全世界，這使得他離開了硬體。
> ✓ 軟體一上線，面對的就是全世界的使用者，所以他離開了硬體。

### 「它」

中文很少用「它」指事物。省略，或把名詞再講一次。

> ✗ 這個工具很簡單。它讓你一行指令跑模型。
> ✓ 這個工具很簡單，一行指令就能跑模型。

### 「擁有」「享有」「具備」

> ✗ 公司擁有 16 名員工。
> ✓ 公司有 16 個人。

### 連接詞太多

「並且」「以及」「然而」「此外」「因此」「與此同時」。中文靠語序和語意接，不用每句掛一個連接詞。先刪掉試試，讀不通再放回去。

### 「將會」「正在…中」

> ✗ 我們將會推出／正在進行中
> ✓ 會推出／正在做

## 4. 英文詞要不要翻

- 業界平常直接講英文的，留英文：PMF、agent、token、demo、MVP、API、PR、group partner、office hour、learning loop、vibe coding。
- 有通行中文的，用中文：創辦人、新創、募資、創投、轉向（pivot，也可以留英文）、開源、伺服器、晶片。
- 第一次出現的冷門英文詞，後面用幾個字解釋，不用括號塞一長串。
- 同一個詞全篇用同一個寫法。不要一下 pivot、一下轉向、一下轉型。
- 引句保留英文原文，旁邊給中文意思。中文意思也要照上面的原則寫，不要逐字翻。

## 5. 人名、公司名、數字

- 外國人名、公司名用原文，不音譯。有通行中文名的華人可以並列一次：陳士駿（Steve Chen）。
- 數字用阿拉伯數字：16 個人、4%、2015 年。概數和成語用國字：兩三個、十幾家、一百萬種。
- 金額照來源的幣別寫，不要自己換算：300 萬美元、170 億美元。
- 英文的 billion 是十億，trillion 是兆。換算最容易出錯，寫完回頭對一次。
